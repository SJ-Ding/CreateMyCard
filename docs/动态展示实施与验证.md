# 动态展示实施与验证

日期：2026-10-25。实现基线：`upstream/main@d1329db5`；工作分支：`codex/presentation-compiler`。
设计依据：[云侧方案设计](云侧方案设计.md)。本记录随实现一并纳入本地提交，尚未发布。

## 已实现

- 模型在现有信息规划阶段提交结构化规则，微服务检查字段、类型、默认／未知状态及复杂度，确定性生成现有端侧表达式。
- 整百日为配置规则：剩余天数为正且对100取模等于0时使用纯色暖主题，其余情况使用纯色蓝主题；支持100、200、300等，不包含0及已过天数。
- 背景、文字、可染色图标和背板共享状态选择；布局、数据、动作、权限不随状态改变。
- 文字槽由转换器登记来源，在辅助文字属性落实；标题、核心数值、单位、动作不能被状态说明替代。
- 整卡与局部配色复用主题角色；按强提醒、提醒、里程碑／达成、普通排序，同级用户要求优先。
- 条件依赖不算可见事实；单位按结果分支检查；联合状态上限64，等价的完整静态结果复用验证，不按属性数量展开。
- 必需规则失败进入现有修复，最终失败不保存普通卡片冒充成功；可选增强整组回退。
- 保存可选展示计划代码块，编辑支持继承、周期修改和删除规则，固定颜色在无关编辑中保留。
- 存档核对交付摘要、结构、动作、数据及文字表达式，一致性检查失败即拒绝编辑。
- 总开关默认关闭、客户端验收名单默认空。App版本、ROM版本和协议必须精确匹配，不从版本大小推断支持。

不新增端侧状态容器、云侧定时任务或动态数据能力。切换发生于既有端侧数据刷新；不承诺零点精准触发。

## 启用与验收

保留默认配置即可关闭能力。只有真实设备验收完成后，才同时设置：

```text
WIDGET_SERVICE_ENABLE_DYNAMIC_PRESENTATION=true
WIDGET_SERVICE_DYNAMIC_PRESENTATION_VERIFIED_CLIENTS=[{"appVersion":"已验收版本","romVersion":"已验收版本","protocolProfileId":"已验收协议"}]
```

上例只说明配置结构，不是已验收名单。普通条件请求在未命中名单时不会生成动态样式；已带展示计划的来源卡也不能在未验收组合上重新编译。

首期只开放受控纯色主题配对。渐变、融球、图片动态切换仍需独立适配和真机测试。
自然语言解释和模型主动建议的合理性需单独评测；类型正确、结构合法不等于业务判断正确。
