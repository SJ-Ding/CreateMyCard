日期：2026-10-23。设计依据：[云侧方案设计](云侧方案设计.md)；回归对照基线：最新 `upstream/main` 的 `56c3e7827f080c3250caac4c580008679811698f`。

## 已实现行为

实际 Fusion 创建及模板失败后进入 Fusion 的产物启用。上游编辑已独立：保留已编译的动态文案、数字、颜色和条件依赖，不重新执行创建或主题流程。
模板、JSX、旧版直接生成入口保持原行为，不主动迁移已经安装的卡片。

- 手机、耳机盒、左右耳电量低于10%时读数和独立单位变红；未连接耳机不将0当成低电量。
- 倒计时根据原始正负天数生成“距离目标还剩／已经”，数字始终非负，0 属于“还剩”。
  原始0至7天变红，超过7天或已经过去恢复原节点主题色；不重新计算日期。
- 用户明确统一文字色时不注入条件颜色；条件描述中的“红色字体”不当成统一配色。
- 阈值和状态色由配置决定，程序复用正式表达式解析器编译，不依赖模型复制或计算表达式。
  创建模型返回普通绑定时程序编译表达式；独立编辑由现有差异保护保留表达式。
- 文字在布局前规范化；两种尺寸按完整动态文案核算预算。主题及兜底后才注入颜色，
  从编译源的语义角色排除标题和动作，不按生成 ID 前缀猜角色。
