# 桌面截图准备与历史记录

当前流程不加载加桌适配器，不执行自动加桌或删除。请先在设备调试页点击“编译并安装项目”，
再在设备上长按“AI卡片调试”，通过“卡片”菜单各添加一张2x2和2x4卡片。
两张卡片必须放在同一个桌面页面，停留该页并关闭菜单后再运行截图。建议同时将应用入口放在该页，
但入口只按`text`或`originalText`等于“AI卡片调试”尝试辅助校验，不存在时不阻塞。
后处理只对两张卡片的同页、规格、可见性和遮挡做强校验，不会自动翻页。
节点与系统卡片边界的宽高必须一致，位置比较允许2px偏差。
完整操作见[运行规范](../../调试平台运行规范.md#桌面卡片截图)。

该目录仅保留历史设备测试记录。旧的单实例加桌认证、空间校准、动作配置及认证命令已经移除，
不再作为后处理运行前置条件。桌面定位只使用返回/Home、UiTest读取和实际边界查询。
