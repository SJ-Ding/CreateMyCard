# 倒计时数据集

共 209 条，全部使用 2×2 尺寸及 GetDateCounter。其中 95 条为单次计时，114 条为周期计时。

- 按事件、计时意图、日期和重复规则合并同义语料。农历和阴历视为同一历法，事件、日期、历法或周期规则不同的样本分别保留。
- 单次倒计时和正计时只传目标日期及所需的历法信息。日期计数每天更新，目标事件只发生一次时仍按单次处理。
- 周期计时传入重复单位及所需的间隔。有明确历史首节点时沿用该节点。只给出重复规则时，以参考日当天或之后的首个匹配日期为测试起点。相同周期的同义语料优先保留明确首节点的版本。
- 正计时按自然日差标注，目标当天显示「就是今天」。2 月 29 日的年度重复样本沿用来源预期，跨年跳过非闰年的行为需端侧验证。

Q001.json–Q209.json 为请求。evaluation/expectations.json 保留全部来源编号并记录保留语料对应的参考日、日期参数和预期结果。参考时区为 Asia/Shanghai。
